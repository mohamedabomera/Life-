# Life Reset — مشروع أندرويد

هذا مشروع WebView يضم ملف HTML الأصلي داخل تطبيق Android بسيط. لا يحتاج إعداد Paymob لكي يعمل.

## بناء APK تلقائيًا
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد باسم `LifeReset`.
2. افتح تبويب **Actions** في المستودع.
3. شغّل workflow باسم **Build Life Reset APK** (أو انتظر تشغيله بعد رفع الملفات).
4. بعد انتهاء البناء، افتح نتيجة التشغيل ثم نزّل Artifact باسم `LifeReset-debug-apk`.
5. فك ضغط الملف على الهاتف وثبّت `app-debug.apk`. قد يطلب Android السماح بالتثبيت من هذا المصدر.

هذا إصدار تجريبي (debug) للتجربة الشخصية، وليس إصدار متجر Play موقّعًا. لا توجد أي مفاتيح دفع أو بيانات Paymob مضمنة.
